# Syed Subhan Hussain — Cyber Security Portfolio

A high-performance interactive 3D cyberpunk portfolio showcasing cybersecurity projects, arsenal, leadership, and credentials.

![Portfolio Preview](/site/images/preview.png)

## 🛡️ About
Portfolio of **Syed Subhan Hussain** — Cyber Security Analyst, IoT & Blockchain Specialist, and Software Engineer (GNDEC Bidar, Class of 2027). Team Leader of **DEFENXIA** (Smart India Hackathon Finalist) and lead organizer of the **HACKTOBER** cybersecurity event.

## ⚡ Features
- **Interactive 3D Hero Section**: Real-time 3D character (`Silent Shadow`) rendered with WebGL and Three.js with full dynamic lighting, post-processing aura bloom, and 360° scroll rotation.
- **Cyber Arsenal & Services Carousel**: 3D interactive Katana blade with rotating frosted-glass cards showcasing security capabilities (Wireshark packet hunting, Nmap scanning, Snort IDS, Metasploit, etc.).
- **Interactive Features & Experience**: Deep dive into DEFENXIA mobile security, vulnerability assessment, and team leadership.
- **Smooth Navigation & Ambient Soundtrack**: Integrated smooth scrolling and optional ambient cyberpunk audio track.
- **Fully Responsive**: Optimized for all devices from mobile to ultra-wide displays.

## 🚀 Quick Start

To run locally:
```bash
# Clone the repository
git clone https://github.com/syedsubhanhussain-sih/syed-subhan-portfolio.git

# Navigate into the site directory
cd syed-subhan-portfolio/site

# Start a local web server (Python 3)
python -m http.server 3000
```
Then open `http://localhost:3000` in your web browser.

## 🛠️ Tech Stack
- **Core**: Vanilla HTML5, Modern CSS, Modular JavaScript (ES modules)
- **3D & Graphics**: Three.js, WebGL shaders, GLTF/GLB models
- **Animation & FX**: GSAP (GreenSock), ScrollTrigger, Lenis Smooth Scroll
- **Audio**: Web Audio API
